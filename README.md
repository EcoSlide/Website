# 🩴 EcoSlides - Environmental Sustainability Platform

> 🌍 Main Website: https://ecoslide.github.io/Website/public/

> A modern website dedicated to promoting sustainable practices and environmental awareness.

## 📋 About

EcoSlides is a web platform designed to educate, inform, and inspire people about environmental sustainability. The site provides comprehensive information about environmental impact, eco-friendly solutions, frequently asked questions, and more.

## ✨ Features

- **Home Page**: Introduces the mission and vision of EcoSlides
- **About Us**: Information about the project and team
- **Impact**: Data and statistics about environmental sustainability
- **Solutions**: Sustainable proposals and eco-friendly alternatives
- **FAQ**: Answers to common questions
- **Search**: Functionality to find content quickly
- **Contact**: Contact form to get in touch

## 🛠️ Technologies Used

- **HTML5**: Web structure and content
- **CSS3**: Styling and responsive design
- **JavaScript**: Interactivity and dynamic features
- **Flag Icons**: Professional iconography

## 🚀 Installation & Usage

### Requirements
- Modern web browser
- Node.js (optional, if you need to run scripts)

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/EcoSlide/Website.git
   cd Website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the website**
   - Open `public/index.html` in your browser, or
   - Use a local server like Live Server in VS Code
